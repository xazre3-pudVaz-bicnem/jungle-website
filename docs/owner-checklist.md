## 情報が確認できたときの反映手順

1. `src/data/company.ts` の該当フィールドに値を入れ、`verified: true` にする
2. `src/data/jobs.ts` の `specs` の `value` を埋める
3. 求人内容を変更したら `jobs.ts` の `updatedAt` を更新する
4. `npm run build` で確認する
5. デプロイ後、Search Console の URL 検査からインデックス登録をリクエストする
6. 求人ページを更新した場合は `npm run indexing:update` を実行する

> **絶対にやらないこと**
> 未確認の情報を推測で埋めること。求人条件の誤りは応募者との信頼問題になり、
> Googleしごと検索では掲載資格の喪失につながります。
