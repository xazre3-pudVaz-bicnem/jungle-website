# 画像の配置場所

`src/lib/images.ts` の `imagePaths` に登録されたファイルをここに置きます。
ファイルが存在しない場合は、黒地に黄色のラインを引いた仮レイアウトが自動で表示されるため、
画像が欠けてもレイアウトが崩れることはありません（壊れた画像は表示されません）。

## 差し替え方法

同名のファイルを置き換えて再ビルドするだけで反映されます。
別のファイル名にしたい場合は `src/lib/images.ts` の `imagePaths` を編集してください。

## 推奨仕様

- 形式：WebP（`next/image` が配信時にさらに最適化します）
- ヒーロー用：横 2000〜2200px／その他：横 1500px 程度
- 1ファイル 200KB 以下を目安に圧縮してください
- **Instagram の CDN URL を直接参照しないでください**（URLが失効します）

## altテキストについて

alt は各ページのコードに日本語で記述済みです。
写真の内容が想定と異なるものに差し替えた場合は、該当ページの `alt` も合わせて修正してください。
